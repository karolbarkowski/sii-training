# SII Training - Introduction to Machine Learning

## Prerequisites
Python > 3.14.4 installed.

Run ``` python --version ``` to check what you have


## PowerShell Setup

Create a new virtual environment:

```powershell
python -m venv .venv
```

Activate the virtual environment:

```powershell
.venv\Scripts\Activate.ps1
```

Install the Python dependencies (can take few minutes...):

```powershell
pip install -r requirements.txt
```
